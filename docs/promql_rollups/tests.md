# PromQL rollups: tests

**Built.** Part A (#742), part B (#744) and the follow-up that chooses the resolution by the query's time range (issue #18) are on `main`; every test below is on `main` with that follow-up. Tiering (#743 part A) and a level's own retention and move age (#743 part B) are on main.

"Live" tests run against one server when `PULSUS_TEST_CLICKHOUSE=1`; "cluster" tests run on the two-shard fixture in CI's cluster job. The last run of `crates/pulsus-read/tests/live_metrics_rollup.rs` recorded during part B's work, nine tests, passed (`measure/results/live-metrics-rollup.txt`); it was not re-run on the merged commit. No cluster run is recorded here.

The live part B cases build the first level by the first-level view's statement with a literal interval, and each later level by its own view's statement run as an insert, a day at most per statement, until a statement writes no run row. Cases that only read a corpus share one database per corpus; cases that cut run rows or add rows build their own. The view's own runs are held by part A's tests and by N1 and N2.
